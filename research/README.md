# research/

Единственное место в репозитории, где допустим Python: прототипы физических моделей, разбор дампов, ноутбуки
для подбора коэффициентов. Код отсюда **не** вызывается production-системой и не дублирует её бизнес-логику.
Результат исследования попадает в прод только как реализация на C# (с тестами) в соответствующем проекте `src/`.
